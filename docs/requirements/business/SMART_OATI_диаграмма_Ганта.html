Редактирование задачи

Окончание, статус и процент направления рассчитываются автоматически по подзадачам.
«Факт завершения» не ведётся для направлений — досрочность учитывается по задачам.

Импорт плана из JSON/CSV

Файл экспортируется кнопкой «Экспорт в JSON/CSV». Импорт после валидации полностью заменяет текущий план и флаги БП/СП.

Новая диаграмма с чистого листа

Будет создан пустой план, который можно наполнить кнопкой «+ Добавить задачу» (сначала выберите «+ Новое направление…»).
В этом браузере будут очищены: задачи плана, каталог исполнителей, флаги БП/СП, порядок направлений, свёрнутые группы, режим дней, список праздников и стили связей. При необходимости сначала сохраните текущий план кнопкой «Экспорт в JSON».
По умолчанию — «Новая диаграмма». Название можно изменить позже кнопкой «Название…».

Название диаграммы

Название отображается в заголовке страницы и сохраняется в плане (в JSON-экспорте — поле project).

Связь

Направление: предшественник → последующая задача. Стиль применяется к стрелке на диаграмме.
Цвет критических и нарушенных связей задаётся автоматически; форма и штрих сохраняются (для циклов — принудительный пунктир).
