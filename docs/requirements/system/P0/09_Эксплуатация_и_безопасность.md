## 2. Домены и cookie

Placeholders:

- frontend: `app.smart-oati.local`;
- API: `api.smart-oati.local`;
- sync: `api.smart-oati.local/ws`;
- Telegram webhook: `api.smart-oati.local/telegram/webhook`.

Cookie:

- `__Host-session` — `Secure`, `HttpOnly`, `SameSite=Lax`, `Path=/`;
- `__Host-remember` — `Secure`, `HttpOnly`, `SameSite=Lax`, `Path=/`;
- `__Host-csrf` — `Secure`, `SameSite=Lax`, `Path=/`, не `HttpOnly`.

CORS:

- allowlist `https://app.smart-oati.local`;
- credentials: true;
- запрещен `*` с credentials;
- разрешенные headers: `Content-Type`, `X-CSRF-Token`, `Idempotency-Key`, `X-Request-ID`;
- exposed: `X-Request-ID`, `X-RateLimit-*`, `Retry-After`.

---

## 3. TLS и сеть

- TLS завершается на Ingress;
- HSTS;
- внутренние сервисы — только внутри кластера;
- gRPC-порты не публикуются;
- mTLS или service-токены;
- NetworkPolicy между сервисами;
- Telegram webhook — прямой endpoint с секретом;
- PostgreSQL и Redis недоступны извне.

---

## 4. Секреты

Хранятся вне репозитория:

- PostgreSQL credentials;
- Redis password;
- broker credentials;
- SMTP credentials;
- Telegram bot token;
- Telegram webhook secret;
- service tokens;
- session/CSRF signing keys;
- JWT/служебные ключи, если используются.

Требования:

- ротация;
- least privilege;
- отдельные credentials на окружение;
- запрет логов секретов;
- secrets не попадают в образы.

## 5. SLO

| Сервис | Доступность | p95 |
|--------|-------------|-----|
| API Gateway | 99,5% | ≤ 300 мс без backend |
| User & Access | 99,5% | login ≤ 500 мс, validate ≤ 50 мс |
| Project / Diagram | 99,5% | read ≤ 300 мс, write ≤ 500 мс |
| Sync / Realtime | 99,5% | доставка ≤ 500 мс |
| Notification | 99,5% | создание ≤ 1 с |
| Audit | 99,5% | запись ≤ 5 с, поиск ≤ 300 мс |

---

## 6. Rate limit

- 300/мин на пользователя;
- 60/мин на IP;
- 10/мин на auth-маршруты;
- тело 10 МБ;
- импорт 50 МБ;
- timeout 5 с;
- import/export 30 с.

---

## 7. Резервное копирование

- ежедневный full backup;
- WAL/PITR;
- отдельные backup для каждой БД;
- проверка восстановления;
- RPO ≤ 24 ч;
- RTO ≤ 4 ч;
- retention: общий аудит 2 месяца, privileged 2 года, проекты 1 год после удаления.
